# OPS400 Option Audit Checklist

Regla maestra:
- Este checklist es solo para auditar batches ya generados.
- La ancla principal de criterio son siempre `batch-01.json` a `batch-04.json` del mismo módulo.
- `Preguntas Operativos` puede consultarse como apoyo secundario.
- Si hay conflicto, mandan los batches 01-04 del módulo.
- Trabajar siempre un solo batch por ejecución.
- Cada batch debe revisarse completo, pero distribuido en `4 subagentes x 5 preguntas`.
- La revisión debe leer y entender `scenario` + 4 opciones de cada reactivo.
- No usar Python ni scripts externos para decidir qué está bien o mal.
- Marcar como completado solo después de guardar y releer el batch final.
